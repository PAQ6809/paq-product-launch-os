# PAQ Product Launch OS Demo Script

## 30 秒介紹版本

PAQ Product Launch OS 是一個商品上市 AI demo。使用者輸入商品照片與基本資料，系統會產出一份完整商品上市企劃書，包含商品定位、競品分析、定價、包裝 brief、商品頁文案、社群貼文、短影音腳本、FAQ、客服話術與首月行銷計畫。現在是 Mock AI Demo，重點是展示商品上市流程與人工審核機制。

## 1 分鐘介紹版本

很多店家有商品，但不知道怎麼把它變成可以上架、可以銷售、可以對外溝通的完整企劃。PAQ Product Launch OS 把商品資料轉成一份可複製、可審核、可匯出的上市報告。

Demo 流程很簡單：先選一個 demo 商品，例如文創小物、3C 配件或生活香氛，直接進入報告頁；報告頁會看到商品定位、市場與競品、包裝方向、商品頁文案、社群素材與首月行銷計畫。每個 section 都可以 Copy、Edit、Approve、Reject，修改後會標記 human_edited，避免 AI 內容未審核就直接上架。

## 3 分鐘完整展示流程

1. 進入首頁
   - 指出定位：「上傳商品資料，AI 產出完整商品上市企劃書」。
   - 說明三個核心價值：商品定位與市場分析、包裝與商品頁文案、社群素材與首月行銷計畫。

2. 點擊 Demo 商品
   - 選擇「文創小物」、「3C 配件」或「生活香氛」。
   - 說明不同商品類別會有不同語氣與策略。

3. 展示報告頁
   - 先指出頁面上方的「目前為 Mock AI Demo」提醒。
   - 展示商品定位、競品分析、定價建議、包裝 brief、商品頁文案、社群貼文、短影音腳本、FAQ、客服話術與首月行銷計畫。
   - 點一個 Copy 按鈕，展示內容可立即複製。
   - 點 Export Markdown / JSON，說明可以交給店家、老師或後續系統使用。

4. 展示人工審核
   - 點 Edit 修改其中一段內容。
   - 儲存後指出 human_edited 標記與 audit log mock。
   - 點 Approve / Reject，說明正式版本會把這些狀態寫進資料庫。

5. 展示 Dashboard
   - 回到 Dashboard，查看商品名稱、類別、生命週期狀態、建立時間與查看報告按鈕。
   - 說明 idea → research → positioning → packaging → listing → marketing → launched → optimizing 的生命週期。

6. 展示建立商品
   - 到 /products/new 填入一個商品。
   - 送出後跳到新商品報告頁。
   - 重新整理後商品仍保存在 localStorage。

## 適合對店家介紹的說法

你不用先想完整品牌策略，只要先把商品名稱、功能、成本、預計售價、客群、風格與銷售平台填進來，系統就能產生第一版上市企劃。這份企劃可以幫你整理商品要怎麼定位、商品頁要怎麼寫、包裝要注意什麼、社群要發什麼、客服可能會被問什麼。現在 demo 不會直接幫你上架，也不會亂保證銷售，而是先把你最缺的上市內容整理出來，再由人審核後使用。

## 適合對創業比賽介紹的說法

PAQ Product Launch OS 解決的是小品牌與電商賣家在新品上市前的內容斷點。多數工具只做單點文案或圖片生成，但商品上市需要定位、競品、定價、包裝、商品頁、社群、客服與優化計畫串在一起。本 demo 展示的是一個商品生命週期工作台：先用 mock AI 產出完整企劃，再透過 human-in-the-loop 審核降低法律與品牌風險，未來可接 OpenAI、Supabase、Shopify、蝦皮、Pinkoi 與 n8n 工作流。
