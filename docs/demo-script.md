# PAQ Product Launch OS Demo Script

## 30 秒介紹版本

PAQ Product Launch OS 是一個商品上市 AI Demo。你只要輸入商品資料，系統就會產出一份完整上市企劃書，包含商品定位、客群分析、競品差異、包裝設計 brief、商品頁文案、社群貼文、短影音腳本、FAQ 與首月行銷計畫。目前是 Mock AI Demo，適合展示流程與驗證店家需求。

## 1 分鐘介紹版本

很多店家有商品，但不知道怎麼把商品變成可以上架、可以銷售、可以對外溝通的完整企劃。PAQ Product Launch OS 把商品資料整理成一份可展示、可討論、可複製、可匯出的上市報告。

Demo 流程很簡單：不用重新填表，直接點三個 demo 商品，分別代表文創小物、3C 配件與生活香氛。進入報告頁後，先看「上市企劃摘要」與商品生命週期，再看定位、客群、競品、定價、包裝、商品頁、社群與首月行銷計畫。每個 section 都可以 Copy、Edit、Approve、Reject；修改後會標記 human_edited，避免 AI 內容未審核就直接上架。

## 3 分鐘完整展示流程

1. 展示首頁
   - 說明主定位：「上傳商品資料，AI 產出完整商品上市企劃書」。
   - 指出三個核心價值：定位與市場分析、包裝與商品頁文案、社群素材與首月行銷計畫。

2. 展示 demo 商品入口
   - 選擇文創小物、3C 配件或生活香氛。
   - 說明 demo 商品不用重新填表，可以快速展示不同商品類型的企劃結果。

3. 展示報告頁
   - 先看「上市企劃摘要」：商品名稱、類別、建議售價、目標客群、核心定位、銷售通路與生命週期狀態。
   - 看 lifecycle progress：idea、research、positioning、packaging、listing、marketing、launched、optimizing。
   - 往下展示商品定位、目標客群、核心賣點、競品分析、定價建議、包裝 brief、商品頁文案、SEO、社群貼文、短影音腳本、FAQ、客服話術、首月行銷計畫與銷售後優化建議。
   - 點 Copy section，說明可以直接貼到文件、商品頁或內部討論。
   - 點 Export Markdown / JSON 或 Copy Full Report，說明可以交給店家、老師、評審或後續系統使用。

4. 展示人工審核
   - 點 Edit 修改其中一段文案。
   - 說明修改後會標記 human_edited。
   - 點 Approve / Reject，說明這是正式上架前的人類審核流程雛形。
   - 指出底部法規與風險提醒：AI 內容、包裝素材、食品、美妝、保健、醫療與平台規則都需要人工檢查。

5. 展示 Dashboard
   - 回 Dashboard 看商品名稱、類別、生命週期狀態、建立時間與查看報告按鈕。
   - 說明 demo 使用 localStorage，重新整理後資料仍會保留。

6. 展示商品輸入頁
   - 到 `/products/new` 建立一個新商品。
   - 填入基本資料後產生 mock 商品上市報告。
   - 說明未來 v0.3 才會接 OpenAI API，目前先驗證 demo 展示與客戶價值。

## 適合對店家介紹的說法

這個 demo 不是直接幫你投廣告，也不是保證商品會爆賣。它先幫你把商品上市前最常卡住的內容整理成一份企劃書：定位、客群、競品差異、包裝文案、商品頁、社群貼文、短影音腳本、FAQ、客服話術與首月行銷計畫。你可以先用這份報告跟設計、行銷、客服或通路窗口討論，再人工審核後上架。

## 適合對創業比賽介紹的說法

PAQ Product Launch OS 把小品牌上市商品時分散的決策流程整理成 AI-assisted workflow。MVP 先用 Mock AI Demo 驗證價值：商品資料輸入後，系統產出可複製、可匯出、可人工審核的上市企劃報告。未來可以接 OpenAI API、Supabase、Shopify、蝦皮、Pinkoi 與 n8n，從企劃報告逐步延伸成商品生命週期管理系統。
