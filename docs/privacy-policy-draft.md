# PAQ Privacy Policy Draft

Draft only. Not legal advice.

PAQ Product Launch OS helps users organize product data, generate AI-assisted launch reports, translate report content, and export professional planning documents.

## Data We May Process

- Account data: email, display name, authentication metadata.
- Product metadata: product name, category, lifecycle status, sales channels.
- Product confidential data: costs, private product strategy, target audience notes, unreleased launch plans.
- AI outputs: generated reports, translations, review notes, export metadata.
- Security data: audit events, export jobs, data requests, hashed IP/user-agent records where enabled.

## Purpose

Data is used to provide product workspace, report generation, translation, export, audit, and account support features.

## AI Providers

If real AI providers are enabled, product inputs and report content may be sent to configured server-side providers such as OpenAI or NVIDIA-compatible APIs. Public demos should remain mock-first unless explicitly configured otherwise.

## Security

PAQ uses Supabase Auth, Row Level Security, server-side session validation, and optional application-level encryption for sensitive payloads. No system can guarantee absolute security.

## User Rights

v0.4.5 includes request records for user data export and account deletion. Production fulfillment requires an operational review workflow.

## Retention

Export job metadata defaults to short retention. Final retention periods must be decided before production launch.
