# Product Analysis Report Template

The professional product analysis report normalizes a `Product` plus `LaunchReport` into a fixed, reviewable structure. Missing data must render as `Not provided`, not disappear from the report.

## Sections

1. Cover
   - Report title
   - Product name
   - Prepared for
   - Generated at
   - Confidentiality notice

2. Executive Summary
   - Product overview
   - Core positioning
   - Top 3 recommendations
   - Key risks

3. Product Profile
   - Category
   - Features
   - Cost
   - Target price
   - Sales channels
   - Lifecycle status

4. Market Positioning
   - Positioning statement
   - Target audience
   - Pain points
   - Differentiators

5. Competitive Analysis
   - Competitor summary
   - Price comparison
   - Positioning gap
   - Recommended angle

6. Pricing Strategy
   - Suggested price
   - Margin notes
   - Promotion strategy
   - Bundle opportunity

7. Packaging Strategy
   - Packaging brief
   - Front copy
   - Back copy
   - Material / visual direction
   - Compliance notes

8. Listing Copy
   - Product title
   - Short description
   - Long description
   - SEO keywords
   - Platform notes

9. Marketing Assets
   - Social posts
   - Video scripts
   - Launch checklist
   - First month plan

10. Customer Communication
    - FAQ
    - Customer service scripts
    - Objection handling

11. Risk and Compliance Notes
    - Legal risk notes
    - Platform policy notes
    - AI content review reminder

12. Next Actions
    - Priority tasks
    - Owner placeholder
    - Due date placeholder

13. Appendix
    - AI provider metadata
    - Validation status
    - Reviewer notes
    - Export metadata

## Export Notes

- Markdown, JSON, HTML, CSV, and ZIP package exports are supported as first-pass formats.
- PDF, DOCX, and PPTX are intentionally out of scope for v0.4.5.
- HTML export must escape dynamic text.
- Export routes must require session and product ownership checks.
